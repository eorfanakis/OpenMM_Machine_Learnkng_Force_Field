# OpenMM_Machine_Learnkng_Force_Field
Hybrid ML/MM MD pipeline using OpenMM, PyTorch, and MACE. Simulates Alprazolam in a lipid membrane. Uses a pre-trained MLFF to intrinsically capture halogen bonding (σ-hole) without virtual sites, dynamically logging Cl - O interactions. Replaces classical ligand forces with ML predictions via openmm-torch.
